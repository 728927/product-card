const numbers = [1, 2, 3, 4, 5]

const sum = numbers.reduce((acc, num) => {
  return acc + num;
}, 0);

console.log(sum); // 15

0+1=1+2=3+3=6+4=10+5=15

numbers - исходный массив чисел.
.reduce(...) складывает элементы массива в аккумулятор acc,
начиная с 0.
Итоговое значение sum равно 15.
Массив собрали в одно значение.

Для этого задаем условие.

Если num текущее значение больше > предыдущего значения

тогда возвращаем num, вернем самое большое знаяение.

если нет, тогда возвращаем acc, чтобы потом взять и проверить это.

const numbers = [1, 2, 40, 3, 4, 50, 5, 10, 20]

const sum = numbers.reduce((acc, num) => {
  return num > acc ? num: acc
}, 0);

console.log(sum); // 50
