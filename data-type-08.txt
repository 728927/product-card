Следующий метод объединения оператор СПРЕД (...)

const a = [1, 2]
const b = [3, 4]
const c = [...a, ...b];
console.log(c); // (4)  [1, 2, 3, 4]
--------------------------------------------------------


const a = [1, 2]
const b = [3, 4]
const c = a.concat(b);
const d = [...a, ...b];
console.log(c); // [1, 2, 3, 4]
console.log(d); // [1, 2, 3, 4]

concat и спред (...) работают одинаково.

спред - более современный метод.

Он позволяет дополнять элементы внутри рассширения: 

const a = [1, 2]
const b = [3, 4]
const c = a.concat(b);
const d = [...a, 99, ...b, 100];

console.log(c); // [1, 2, 3, 4]
console.log(d); // [1, 2, 99, 3, 4, 100]


Будем знать что есть оператор concat , 
но используем спред (...)

Методы массива

Есть у нас методы которые изменяют массивы.
Есть методы которые не изменяют массивы.

1. Изменяют массив
2. Создают новый массив

Метод push
Создаем array (массив) и добавим к нему метод push 

const array = [1, 2, 3, 4]
array.push(5, 6)

console.log(array) // (6) [1, 2, 3, 4, 5, 6]

push добавляет новый элемент в конец массива.
новые элементы столько сколько мы передадим массиву.
-------------------------------------------------------

Метод pop - удаляет последний элемент массива.

И на него передавать ничего не надо, он удаляет последний элемент

const array = [1, 2, 3, 4]
array.pop(); 

console.log(array)  // (3) [1, 2, 3]
---------------------------------------------

Есть метод unshift - добавляет элемент в начало массива.

const array = [1, 2, 3, 4]
// array.push(5, 6)      // (6) [1, 2, 3, 4, 5, 6]
// array.pop();         // (3) [1, 2, 3]
// array.unshift(0)    // (5) [0, 1, 2, 3, 4]
// array.shift();     //(3) [2, 3, 4] 

console.log(array)  
------------------------------------------------------

push -     добавляет новый эл. в конец массива
pop -      удаляет последний эл. массива
unshift -  добавляет эл. в начало массива
shift -    удаляет первый эл. массива
--------------------------------------------------

Это четыре основные методы изменения массива.
Они изменяют исходный массив array
